具身世界模型实验室 · vla-world-model-lab

PyTorchDreamer RSSMMuJoCo世界模型 OpenVLAVLA数据集

基于 Dreamer 范式的轻量化具身世界模型。从离线轨迹学习「图像 + 动作 → 隐状态 → 下一帧图像 / 奖励」的动力学，在隐空间训练想象策略，并用完整消融实验回答各设计选择的有效性。

  • 20 步开环想象测试集 SSIM 0.7511、奖励 MAE 0.0242，均超过自设门槛。
  • 同口径动力学消融：RSSM 20 步 PSNR 23.71 dB vs 纯前馈 MLP 17.61 dB。
  • KL 与 free bits 消融：移除 KL 后从第 1 步崩塌；free_bits 调参带来 +5.7 dB。
  • 想象策略探针回报 -0.04 → +0.85；同时如实记录真实环境 0% 成功率的 sim-to-real 瓶颈。
  • 想象步长 / 奖励头 / 样本效率 / 50 场景泛化全套消融，附机器可读结果与图表。
  • 接入 OpenVLA 7B 打通单帧 / 单步 / 回合级闭环，bf16 单步 0.305 s（3.65 Hz），如实记录零样本 0/3 成功率与域差距排查。
  • 构建自定义 VLA 数据集：25 条轨迹 / 928 帧，5 类共 20 条指令模板全覆盖，起点 ±0.05 m 随机化、带时间戳与质量筛选。
  • 回合级语言指令标注与三元组配对：指令 / 图像序列 / 动作序列一一对应，附数据索引表与 task_index 映射，校验通过。
